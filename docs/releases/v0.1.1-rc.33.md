# Xray Pilot v0.1.1-rc.33

Windows x64 本地验证版，在 `v0.1.1-rc.32` 的基础上，新增独立卡片式 **端口转发（`dokodemo-door`）** 管理、全链路引擎/PAC 兼容适配，以及诊断页路由静态预测输入框自动聚焦与全选。**本版尚未发布到 GitHub Release**。

## 本次变化

- **端口转发（`dokodemo-door`）可视化管理（`crates/xray-manager-app`、`crates/xray-config`、`crates/xray-runtime`、`crates/xray-pac`）**：
  - 在「配置」新增 **「端口转发」** 标签页与新增/编辑弹窗：支持设置备注名、本机监听范围（`127.0.0.1` / `0.0.0.0` / 自定义 IP）、自动空闲端口建议、协议（`TCP` / `UDP` / `TCP+UDP`）、目标地址与端口（支持粘贴 `host:port` 自动拆分）以及目标出站选择。
  - 自动在标准 Xray JSON 中成对同步 `dokodemo-door` 入站与置顶 `inboundTag` 路由规则；支持卡片复选框**停用暂存**（从发往 Core 的 JSON 移除监听但将参数与扩展字段安全保留于 `workspace`）。
  - 实时检测与现有入站/转发同端口冲突、缺失出站、`0.0.0.0` 局域网无认证暴露警告（含应用前预览确认）及内网目标提示；在「分流规则」页标注自动置顶的联动规则，且「开启 Sniffing」自动跳过 `dokodemo-door` 入口。
  - `xray-runtime` 就绪探针对 TCP `dokodemo-door` 执行建连检查、对纯 UDP 给出明确提示；`xray-config` 允许 `dokodemo-door` 端口转发进入完整依赖覆盖且避免规则误报冲突；`xray-pac` `AutoRules` 编译跳过仅作用于 `dokodemo-door` 的 `inboundTag` 规则，不破坏系统代理 PAC 的 `DIRECT` 兜底。
  - 「总览」页展示运行中端口转发计数与跳转入口，「诊断」页「入站 Tag」支持快捷选择运行时入站 Tag。
- **诊断页路由静态预测输入体验优化（`crates/xray-manager-app`）**：
  - 路由静态预测的「目标域名或 IP」与「端口」输入框支持聚焦自动全选，点击「预测命中规则与出站」或按回车触发后自动重新聚焦并全选原文本，方便连续输入测试。
