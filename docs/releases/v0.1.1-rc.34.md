# Xray Pilot v0.1.1-rc.34

Windows x64 本地验证版，在 `v0.1.1-rc.33` 的基础上，完成端口转发功能与全界面的 1:1 交互对齐收口。**本版尚未发布到 GitHub Release**。

## 本次变化

- **总览页**：新增独立 **「运行中端口转发清单」** 卡片，逐条展示备注名、协议、`监听地址:端口 → 目标地址:端口（出站）` 以及「直连模式下依然独立监听」说明与快捷管理按钮。
- **配置页列表与页签动态计数**：左侧「我的配置」卡片显示 `· N 条转发`，页签栏显示 `端口转发 (N)`；应用预览弹窗摘要同步展示端口转发映射详情。
- **「配置 → 节点」引用保护**：节点卡片标题直接显示 `被 N 条端口转发引用`（含活跃与停用暂存转发）；当节点仍被已停用暂存的转发引用时禁止直接删除并提示。
- **「配置 → 分流规则」与「原始 JSON」联动**：
  - 置顶联动卡片改用独立浅底边框区块呈现备注、`监听:端口 (协议) → 目标:端口` 及 `inboundTag → outboundTag` 完整链路。
  - **「更多与源码 → 原始 JSON」** 下方在存在停用条目时展示可折叠的 **`工作区停用端口转发暂存（N 条 · 不写入 Core JSON）`** 只读 JSON。
- **「诊断」逐条入口明细与快捷回填**：
  - 「本地入口」下新增可折叠 **「入口探针明细」**（存在转发时默认展开），逐条列出 HTTP/SOCKS/Mixed 与 `dokodemo-door` 的 TCP 监听就绪 / UDP 转发已校验状态。
  - 路由静态预测新增 **「快捷入站」** 选签，点击 `pf-*` 转发 Tag 自动将对应目标域名/IP、端口及网络协议填入预测表单。
- **卡片与弹窗体验**：端口转发卡片中间流向改用带边框浅底子块突出呈现；新增/编辑弹窗支持点击「自定义 IP」立即高亮并全选、支持回车快捷保存有效草稿。

## 验证

在构建打包前执行 `cargo fmt --all -- --check`、Linux 与 `x86_64-pc-windows-gnu` 双目标严格 Clippy（`-D warnings`）、全工作区回归测试（275 passed, 0 failed），以及 Windows x64 交叉编译与 `--validation` 包校验。
