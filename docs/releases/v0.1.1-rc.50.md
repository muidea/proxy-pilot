# Proxy Pilot v0.1.1-rc.50

Windows x64 本地验证版，在 `v0.1.1-rc.49` 的基础上统一 **「总览」双卡视觉样式、单行防折行排版与三层功能按钮对称排布**，并加固 Unix 并发启动子进程时的瞬态 `ETXTBSY` 重试处理。**本版尚未发布到 GitHub Release**。

## 本次变化

- **「总览」双卡样式统一与单行防折行（[widgets.rs](../../crates/proxy-manager-app/src/widgets.rs)、[layout.rs](../../crates/proxy-manager-app/src/ui/layout.rs)）**：
  - 左卡「连接与系统代理状态」与右卡「端口转发与隧道」统一采用 `responsive_header` + 分隔线 + 两组 `responsive_compact_header` 分段标题 + `compact_subcard` 嵌套子卡 + 底部单行 Accent `banner_box` 结构；桌面宽屏维持 `48% / 52%` 分栏比例。
  - 新增单行键值辅助 `kv_row_singleline`（固定 `104 px` 键宽列 + 单行 `.truncate()` + 悬停完整提示）；移除左卡中与右卡重复的转发/SSH 计数行，并将 `生效 PAC 策略` 精简为单行（如 `指定代理 · 24299 条生效`），隧道条目地址与经由说明保持单行展示，消除多行折行与孤立括号问题。
- **三层功能按钮 1 对 1 对称排布（[widgets.rs](../../crates/proxy-manager-app/src/widgets.rs)、[layout.rs](../../crates/proxy-manager-app/src/ui/layout.rs)）**：
  - **卡片顶栏（`36 px`）**：双卡右上角统一为“1 蓝主按钮 + 1 灰次按钮”——左卡为「管理配置」（主按钮，无已保存代次时为「选择配置」）+「路由诊断」（次按钮），镜像右卡「+ SSH 隧道」（主按钮）+「管理转发」（次按钮）。
  - **分段标题栏（`26 px` 标题行 + `24 px` 紧凑操作）**：新增 `compact_chip_enabled` 并复用至 `compact_button_enabled`；左卡「Core 状态」右侧安置「重启 Core / 停止 Core」（或「启动 Core」），「系统代理」右侧安置「直连 / PAC / 全局」胶囊切换器，与右卡「SSH 隧道」右侧「全部启动 / 全部停止」排布一致。
  - **子卡条目行尾（`24 px` 紧凑按钮）**：左卡第 1 子卡内将「代理可用性」的「重测 / 诊断详情」放回该状态行右侧，并在「本机 HTTP 入口」右侧提供「复制」（自动将 `0.0.0.0:` 转为 `127.0.0.1:`），与右卡转发/隧道条目的「复制」「启动 / 停止」一致。
- **Unix `ExecutableFileBusy` (`ETXTBSY`) 瞬态重试（[lib.rs](../../crates/proxy-runtime/src/lib.rs)、[process.rs](../../crates/proxy-runtime/src/process.rs)）**：
  - 在类 Unix 平台执行版本检查 `output()` 与启动进程 `Process::spawn` 遇到 `ExecutableFileBusy (os error 26)` 时增加指数退避重试（最多 6 次），避免多线程并行 `fork()/execve()` 触发测试或启动抖动。
- **总览按钮层级回归测试（[tests.rs](../../crates/proxy-manager-app/src/ui/tests.rs)）**：
  - 新增 `enclosing_rect_below` 排除顶部导航栏同名标签干扰，并在 `overview_action_buttons_match_standard_control_height` 中覆盖双卡顶栏 `36 px` 主次按钮水平对齐与分段/条目 `24 px` 紧凑按钮行列对齐断言；在 `proxy-runtime` 新增 `version_retries_transient_executable_file_busy` 回归测试。

## 验证

在构建打包前执行 `cargo update --workspace --offline`、`cargo fmt --all -- --check`、`git diff --check`、Linux 与 `x86_64-pc-windows-gnu` 双目标严格 Clippy（`-D warnings`）、全工作区 `--locked` 回归测试（**310 项通过**：含 `proxy-manager-app` **141 项**、`proxy-supervisor` 库 **60 项**、`proxy-config` **33 项**、`proxy-pac` **20 项**、`proxy-runtime` **13 项**、`proxy-model` **1 项**、`windows-integration` **11 项**、集成回归 **31 项**，7 项需 `XRAY_TEST_CORE` 的环境专项按预期忽略），以及 Windows x64 release 交叉编译与 `scripts/package-windows.py --validation` CRC / 指纹校验。
