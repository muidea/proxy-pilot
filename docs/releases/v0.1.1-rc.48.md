# Proxy Pilot v0.1.1-rc.48

Windows x64 本地验证版，在 `v0.1.1-rc.47` 的基础上新增 **Xray 代理可用性自动探测、总览分级展示、五步诊断报告与探测设置**。**本版尚未发布到 GitHub Release**。

## 本次变化

- **协议与后台非阻塞探测引擎（[proxy-model](../../crates/proxy-model/src/lib.rs)、[proxy-runtime](../../crates/proxy-runtime/src/lib.rs)、[proxy_probe.rs](../../crates/proxy-supervisor/src/proxy_probe.rs)、[lib.rs](../../crates/proxy-supervisor/src/lib.rs)）**：
  - 新增 `ProxyProbeConfig`、`ProxyAvailabilityState`、`DiagnosticStep`、`ProxyProbeSample`、`ObservatoryOutboundStatus`、`ProxyAvailability` 及指令 `Command::CheckProxyAvailability`、`Command::SaveProxyProbeConfig`。
  - 基于纯 Rust `rustls` + `tokio-rustls`（`ring` 后端）+ `webpki-roots` 实现无 `aws-lc-rs` 依赖的探测客户端，同时支持 `https://` 与 `http://` 目标，通过真实 TLS 握手避免仅收到 `CONNECT 200` 而上游断流导致的假阳性误判。
  - 直接通过运行代次中的 Xray 本地入站（`http` / `mixed` 的 `CONNECT` 与 `GET`，或 `socks` 入站 SOCKS5 域名直透及 `accounts` 认证）探测连通性，不向 Core 原生 JSON 注入或修改任何字段。
  - **防抖、托盘降频与链路关联**：自动探测首次失败进入 `Degraded` 并于 `3s` 后自动复测，连续 2 次失败才置为 `Unavailable`；窗口隐藏进入托盘后自动降频至 `120s`，恢复前景活动后立即补测；结合静态路由模拟（识别 `DirectOnly`）、可选 PAC `FindProxyForURL` 判定以及只读读取 Xray 原生 `metrics/listen` `/debug/vars` `observatory` 指标，生成 5 步诊断报告并保留最近 10 次探测样本，持久化配置于 `config/proxy-probe.json`。
- **分级 UI 展示与诊断导出（[app.rs](../../crates/proxy-manager-app/src/app.rs)、[ui.rs](../../crates/proxy-manager-app/src/ui.rs)、[layout.rs](../../crates/proxy-manager-app/src/ui/layout.rs)、[diagnostics.rs](../../crates/proxy-manager-app/src/ui/diagnostics.rs)、[settings.rs](../../crates/proxy-manager-app/src/ui/settings.rs)）**：
  - **总览与顶栏**：顶栏仅在 `Unavailable` / `Degraded` / `DirectOnly` 时追加简洁后缀（`· 代理不可用` / `· 代理波动` / `· 未走代理`）；总览左卡新增 `代理可用性` 紧凑行（状态徽章 + `重测` + `诊断详情`），健康状态下不展示冗长链路与时间文字，仅异常时展示简短提示；探测进行期间自动提速 `GetStatus` 轮询至 `500ms`。
  - **诊断页**：顶部新增「代理可用性诊断报告」卡片，提供结论摘要、修复建议、一键 `立即重新诊断`、`复制诊断报告`（`format_proxy_diagnostic_report` 导出凭据脱敏 Markdown）、按指定 HTTP/HTTPS URL 单次测试、五步链路核查、可选只读 Xray Native Observatory 指标以及近 10 次通过率与延迟条形图。
  - **设置页**：新增 **设置 → 代理探测**（`SettingsTab::Probe`）独立保存与热生效应用自动探测开关、周期、托盘降频、超时时间及默认目标地址。
- **回归测试扩充（[proxy_probe.rs](../../crates/proxy-supervisor/src/proxy_probe.rs)、[ui/tests.rs](../../crates/proxy-manager-app/src/ui/tests.rs)、[app_tests.rs](../../crates/proxy-manager-app/src/app_tests.rs)）**：
  - 新增 8 项 `proxy_probe` 单元测试（URL 解析校验、HTTP/SOCKS5 入站探测、`CONNECT 200` 断流防假阳性、直连/PAC 第五步关联、防抖状态转移、Observatory 解析及配置持久化）与前端 `proxy_availability_overview_diagnostics_and_settings_flow` 及多尺寸自适应渲染覆盖。
