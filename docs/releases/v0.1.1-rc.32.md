# Xray Pilot v0.1.1-rc.32

Windows x64 本地验证版，在 `v0.1.1-rc.31` 的基础上，响应实机验证反馈进一步完善 PAC 状态可视化、PAC 测试输入交互以及 Xray Core 日志级别调节。**本版尚未发布到 GitHub Release**。

## 本次变化

- **直观展示正在生效的 PAC 策略（`crates/xray-model`、`crates/xray-supervisor`、`crates/xray-manager-app`）**：
  - 在 `PacPublication` 中持久化记录 PAC `mode` 与规则/域名摘要；`Supervisor::apply` 在应用 PAC 时生成对应策略摘要。
  - PAC 页面顶部新增 **「当前生效的 PAC 状态」** 卡片，展示当前系统代理接管状态、正在生效策略（模式名称与摘要）、所属配置、PAC 服务状态、可复制的 PAC URL、与当前编辑草稿是否一致提示，以及可折叠的**正在生效 PAC 脚本内容**查看器。
  - 总览页代理状态区与日志诊断区同步展示当前「生效 PAC 策略」。
- **PAC 测试输入框自动聚焦并全选文本（`crates/xray-manager-app`）**：
  - 为 `singleline_select_all` 控件在获得焦点时自动全选文本；涵盖 PAC 测试 URL、GeoSite 搜索、域名添加与域名筛选框。
  - 在 PAC 测试区点击**「测试命中结果」**或按下回车触发测试后，自动重新聚焦并全选「测试 URL」输入框中的内容，可直接键入下一条待测 URL。
- **支持调整 Core 日志输出级别（`crates/xray-manager-app`）**：
  - 支持将当前配置草稿的 `log.loglevel` 在 `warning`、`info`、`debug`、`error`、`none` 间切换，并随配置草稿自动保存。
  - 在 **日志** 页顶部提供「Core 日志输出级别」选择器、当前运行级别提示及一键**「应用到 Core」**操作，并在 **配置 → 更多与源码 → 本地入口** 同步提供设置入口。

## 验证

在构建打包前执行 `cargo fmt --all -- --check`、Linux 与 `x86_64-pc-windows-gnu` 双目标严格 Clippy（`-D warnings`）、全工作区回归测试，以及 Windows x64 交叉编译与包校验（`--validation` 本地验证包）。
