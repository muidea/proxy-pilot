# Xray Pilot v0.1.1-rc.30

Windows x64 本地验证版，在 `v0.1.1-rc.29` 的基础上，放开 Global / PAC 模式下入站 `0.0.0.0` / `::` 通配监听支持，并将全链路持久化配置与运行时产物路径改为相对于数据目录的便携相对路径，避免更换机器或调整磁盘目录后路径失效。**本版尚未发布到 GitHub Release**。

## 本次变化

- **入站通配监听 `0.0.0.0` / `::` 支持（`crates/xray-runtime`、`crates/xray-manager-app`、`crates/xray-supervisor`）**：
  - 允许 `http` / `mixed` 入站在 PAC 与 Global 模式下监听 `0.0.0.0` 或 `::`，通过 `local_bind_target` 在内部就绪探测、系统全局代理与 PAC `PROXY` 代理目标中自动映射为 `127.0.0.1` / `::1`（仍拦截其它非回环/局域网单播地址），同步更新引导与 PAC 页面提示文案。
- **全配置与持久化路径相对化迁移（`crates/xray-model`、`crates/xray-config`、`crates/xray-supervisor`、`crates/xray-manager-app`）**：
  - 在 `xray-model` 新增 `normalize_lexical`、`to_portable_path`、`resolve_path`、`to_portable_string`、`resolve_string`，统一以数据目录（`root`）为锚点保存 `/` 分隔相对路径（同目录为 `.`、同盘兄弟目录为 `../...`，跨盘或 UNC 路径保持原样），运行时按 `root` 还原并向后兼容历史绝对路径。
  - Supervisor 将 `Settings.core_path`、`Candidate.config_path`、`Candidate.core.path`、`Resources`、`asset_root.txt` 与 `PacPublication.path` 均以相对路径持久化与参与签名校验，运行时经 `resolve_candidate` / `verify_in` 解析后交由 `xray_runtime` 与 `PacServer` 执行。
  - Manager GUI 在读取设置、选用受管依赖、通过文件选择器选取 Core、导入配置自动关联资源目录及保存设置时统一保存相对路径，并在 PAC Geo 缓存刷新时按 `root` 解析读取 `.dat` 文件。

## 验证

在构建打包前执行 `cargo update --workspace --offline`、`cargo fmt --all -- --check`、`git diff --check`、Linux 与 `x86_64-pc-windows-gnu` 双目标严格 Clippy（`-D warnings`）、全工作区回归测试、`git commit`，以及 Windows x64 交叉编译与包校验。
