# Proxy Pilot v0.1.1-rc.41

Windows x64 本地验证版，在 `v0.1.1-rc.40` 的基础上，将 **顶栏版本信息移至右上角**，保持品牌与状态区在窄/宽窗口下都清晰不拥挤。**本版尚未发布到 GitHub Release**。

## 本次变化

- **顶栏版本号移至右上角**：
  - 将 `v0.1.1-rc.41` 版本标签从左侧品牌/状态徽章后方移至顶栏右侧末端。
  - 宽屏单行顶栏下位于右侧导航栏（`总览 → 配置 → PAC → 日志 → 诊断 → 设置`）之后、紧贴右上角；窄屏双行顶栏下位于第一行右上角，第二行独立展示导航标签。
  - 新增 `top_bar_places_version_label_in_top_right_corner` 布局回归测试，覆盖浅色/深色主题与 `760` / `1020` / `1100` 宽度下的右上角对齐与导航顺序。

## 验证

在提交与构建打包前执行 `cargo fmt --all -- --check`、`git diff --check`、Linux 与 `x86_64-pc-windows-gnu` 双目标严格 Clippy（`-D warnings`）、全工作区 `--locked` 回归测试（**284 项通过**，含 `proxy-manager-app` **129 项**，7 项需 `XRAY_TEST_CORE` 的环境专项按预期忽略），以及 Windows x64 release 交叉编译与 `scripts/package-windows.py --validation` CRC / 指纹校验。
