# Proxy Pilot v0.1.1-rc.47

Windows x64 本地验证版，在 `v0.1.1-rc.46` 的基础上完成 **总览界面专项显示优化** 与 **全应用多尺寸窗口自适应布局收口**。**本版尚未发布到 GitHub Release**。

## 本次变化

- **总览界面专项优化（[widgets.rs](../../crates/proxy-manager-app/src/widgets.rs)、[layout.rs](../../crates/proxy-manager-app/src/ui/layout.rs)）**：
  - 将 `render_badge` 重写为基于 `into_galley` + `allocate_exact_size` 的原子级行内组件，彻底修复窄宽度下 `horizontal_wrapped` 尾部把 `运行中` 竖排挤压成 `运\n行\n中` 及右侧溢出边框的问题，并在顶部栏对过长运行配置名执行 `ellipsize(..., 18)` 截断。
  - 左侧「连接与系统代理状态」卡片新增 `SSH 隧道` 运行汇总 `kv_row`；将总览双列布局断点上调至 `860px`（宽屏左卡按 `46%`、区间 `[400px, 560px]` 分配），保持左右卡片视觉均衡。
  - 右侧「端口转发与隧道」卡片改为 `compact_subcard` + `responsive_compact_header` 双行结构：首行左列展示名称与状态徽章（移除冗余 `(TCP · SSH)` 后缀），右列放置紧凑 `24px` 操作按钮（`复制`、`启动`/`停止`、≥2 条时的 `全部启动`/`全部停止`）；次行单行展示 `listen:port -> target_host:target_port` 与所属跳板机/出站信息。
- **配置页与全应用多尺寸窗口自适应（[widgets.rs](../../crates/proxy-manager-app/src/widgets.rs)、[ui.rs](../../crates/proxy-manager-app/src/ui.rs)、[profiles.rs](../../crates/proxy-manager-app/src/ui/profiles.rs)、[guided_config/ui.rs](../../crates/proxy-manager-app/src/guided_config/ui.rs)、[pac.rs](../../crates/proxy-manager-app/src/ui/pac.rs)、[diagnostics.rs](../../crates/proxy-manager-app/src/ui/diagnostics.rs)、[settings.rs](../../crates/proxy-manager-app/src/ui/settings.rs)、[dialogs.rs](../../crates/proxy-manager-app/src/ui/dialogs.rs)）**：
  - 新增 `responsive_header` / `responsive_compact_header`（高于阈值使用 `egui::Sides::new().shrink_left().wrap()` 贴边排布，低于阈值自动堆叠换行）、`compact_button_enabled`、`compact_subcard` 与 `ellipsize`；同步收紧 `kv_row` 与 `line()` 的左侧标签列宽并约束值列折行。
  - **配置页**：侧边配置列表断点上调至 `840px`（列表宽 `20%`、区间 `[204px, 256px]`），窄屏横向条采用统一 `188px` 卡片并配完整悬停提示；编辑器标签栏与代理草稿控件在 `>= 750px` 同行双侧排布；修复 `entry_picker` 等 `ComboBox` 改用 `max_rect().width()` 计算宽度；统一将「端口转发 / SSH 隧道 / SSH 跳板机 / SSH 凭证」与「节点 / 分流规则」卡片头部切换为 `responsive_header`，并精简 SSH 跳板机/凭证简介文案避免中屏高度下首卡按钮落入折叠区。
  - **PAC / 诊断 / 日志 / 设置 / 弹窗**：修复 PAC 嵌套行与筛选/下拉框宽度、视口自适应列表高度及 `ScrollArea::both()` 生效脚本预览；诊断页入站就绪列表升级为自适应 `compact_subcard`、折叠区重算 `adv_field_width` 并调整延迟探测输入宽度；日志页引入 `viewport_height` 驱动动态滚动区高度、搜索框/工具栏与单行复制预留间距；设置与弹窗同步优化路径与 `ssh -L` / 跳板机选择框自适应换行。
- **多尺寸自动化回归测试（[tests.rs](../../crates/proxy-manager-app/src/ui/tests.rs)）**：
  - 新增 `overview_ssh_tunnel_cards_and_badges_never_clip_or_collapse_vertically`、`profiles_page_adapts_across_window_sizes_without_clipping_headers_or_controls`、`all_pages_render_cleanly_without_overflow_or_overlap_across_window_sizes`，覆盖全部 **19** 个界面视图 × **6** 档窗口尺寸（`760×500` 至 `1920×1040`）× 浅色/深色双主题下的无文本重叠、无水平溢出与状态徽章不挤压校验。
