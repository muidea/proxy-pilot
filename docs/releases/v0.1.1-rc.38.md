# Xray Pilot v0.1.1-rc.38

Windows x64 本地验证版，在 `v0.1.1-rc.37` 的基础上，新增 **PAC 设置与当前激活配置自动联动及热同步**，并将 **总览页默认隐藏「最近活动与版本」卡片**。**本版尚未发布到 GitHub Release**。

## 本次变化

- **PAC 设置自动跟随当前激活配置并支持热同步**：
  - 应用配置（含快捷启用与预览确认）或从状态弹窗 / 托盘菜单切换为 PAC 模式时，自动结合目标配置 JSON、HTTP/Mixed 入站与 GeoData 编译生成最新 PAC 脚本。
  - PAC 页绑定目标改为当前已提交运行中的激活配置（`active_pac_target()`），即使在「配置」页浏览其他未应用配置也不会误触「与本页当前编辑不一致」告警，并展示「已自动跟随当前激活配置」提示徽章。
  - 在 Core 运行 PAC 模式期间修改分流策略、GeoSite 选区、域名规则、批量导入/提取、端口或高级脚本时，自动触发 `SetProxyMode(Pac)` 热更新生效，无需再手工二次点击「检查并应用 PAC」。
- **总览界面默认不显示「最近活动与版本」**：
  - 在 `Workspace` 新增 `overview_show_activity`（默认 `false`），总览页面默认仅展示「连接与系统代理状态」和「运行中端口转发清单」双卡片。
  - 如需查看该卡片，可在「设置 → 外观」勾选开启「在总览页显示「最近活动与版本」」，卡片右上角亦提供快捷「隐藏」按钮。

## 验证

在提交与构建打包前执行 `cargo fmt --all -- --check`、Linux 与 `x86_64-pc-windows-gnu` 双目标严格 Clippy（`-D warnings`）、全工作区 `--locked` 回归测试，以及 Windows x64 release 交叉编译与 `scripts/package-windows.py --validation` CRC / 指纹校验。
