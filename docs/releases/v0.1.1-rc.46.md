# Proxy Pilot v0.1.1-rc.46

Windows x64 本地验证版，在 `v0.1.1-rc.45` 的基础上完成 **SSH 隧道配置全链路交互优化**（严格保持本地代理与本地转发通道产品边界，不引入 SFTP/FTP、不翻转为远端主机视角、不做外部终端桥接）。**本版尚未发布到 GitHub Release**。

## 本次变化

- **协议与后台能力扩展（[proxy-model](../../crates/proxy-model/src/lib.rs)、[proxy-supervisor](../../crates/proxy-supervisor/src/lib.rs)、[ssh_store.rs](../../crates/proxy-supervisor/src/ssh_store.rs)、[ssh_tunnel.rs](../../crates/proxy-supervisor/src/ssh_tunnel.rs)）**：
  - 新增 `Command::TestSshHost` 与 `SshHostTestResult` 只读连接测试能力，支持在不落盘凭证的前提下完成真实 TCP 握手、SHA256 Host Key 指纹校验、密码/私钥认证检测并返回 RTT。
  - `SaveSshHost` 新增可选 `inline_credential`，支持新建 SSH 跳板机时原子性同步新建并加密保存关联凭证（校验失败时不留下孤儿凭证）。
  - `SaveSshForward` 新增 `start_now` 支持「保存并立即启动」；新增 `StartAllSshForwards` / `StopAllSshForwards` 支持多条 SSH 隧道批量启停。
- **表单解析、智能拆分与默认友好度（[port_forward.rs](../../crates/proxy-manager-app/src/port_forward.rs)）**：
  - 支持 `ssh -L [bind:]lport:thost:tport [user@host] [-p port] [-l user]` 命令解析（含 IPv6 方括号地址与跳板机自动匹配），以及跳板机地址粘贴/失焦自动拆分 `user@host:port`。
  - 提供常见服务端口预设（`22 SSH` / `3306 MySQL` / `5432 PG` / `6379 Redis` / `8080 Web` / `3389 RDP`）、隧道/跳板机/凭证名称留空自动命名，以及本机监听端口实时冲突检测与一键「改用空闲端口」。
  - `check_form_error_with_optional_config` 允许在 Xray 草稿 JSON 语法错误时独立校验和保存 SSH 隧道。
- **界面与弹窗交互收口（[layout.rs](../../crates/proxy-manager-app/src/ui/layout.rs)、[profiles.rs](../../crates/proxy-manager-app/src/ui/profiles.rs)、[dialogs.rs](../../crates/proxy-manager-app/src/ui/dialogs.rs)、[widgets.rs](../../crates/proxy-manager-app/src/widgets.rs)、[app.rs](../../crates/proxy-manager-app/src/app.rs)）**：
  - **总览与顶栏**：顶栏汇总运行中 SSH 隧道数量（Core 停止时独立提示）；总览「端口转发与隧道」增加 `+ SSH 隧道`、≥2 条隧道时的 `全部启动` / `全部停止`、单行 `复制` 监听地址及 `局域网` 暴露标记，并在总览和端口转发页补充 SSH 运行态定期轮询。
  - **配置 → 端口转发**：彻底解耦 Xray JSON 语法错误对 SSH 隧道管理的阻塞（Xray 区域展示语法错误提示并仅禁用 Xray 编辑与 `+ Xray 转发`，上方 SSH 隧道完全可用）；分离 `+ SSH 隧道` 与 `+ Xray 转发` 入口，新增隧道 `复制地址`、`克隆` 与批量启停；「SSH 跳板机」卡片新增 `+ 转发` 快捷建隧道与 `测试连接` 内联反馈。
  - **三类弹窗优化**：修复父子弹窗切换返回机制，落地 `ssh -L` 一键解析填入（含「按解析结果新建跳板机」）、跳板机内联填写新凭证、常见端口预设芯片、`同目标端口`、`改用空闲端口`、动态自动命名占位符与 `保存并立即启动` 闭环。
  - 新增交互设计原型归档 [ssh-tunnel-ux.html](../ui-prototype/ssh-tunnel-ux.html) 及对应单元与界面回归测试。
