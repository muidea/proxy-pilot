# Proxy Pilot v0.1.1-rc.39

Windows x64 本地验证版，在 `v0.1.1-rc.38` 的基础上，完成 **Proxy Pilot 全面更名**、**SSH 凭证管理与纯 Rust SSH 隧道端口转发（含总览按需启停，保留原有 Xray 转发）**，并修复草稿自动保存后重启 Core 误报 `ASSET_REVISION_CONFLICT` 的问题。**本版尚未发布到 GitHub Release**。

## 本次变化

- **项目全面更名为 Proxy Pilot（方案 B）**：
  - 内部 workspace crates（`proxy-model`、`proxy-config`、`proxy-pac`、`proxy-runtime`、`proxy-supervisor`、`proxy-manager-app`）、3 个可执行文件（`proxy-pilot.exe`、`proxy-supervisor.exe`、`proxyctl.exe`）、窗口与托盘品牌、Named Pipe 前缀、Windows 自启计划任务前缀与打包产物（`proxy-pilot-<ver>-windows-x64.zip`）全部切换为 `Proxy Pilot`。
  - 从 `rc.38` 及以前旧目录升级时，请先通过旧版托盘/界面「退出程序（停止 Core 并恢复代理）」（如有开启旧版开机自启请先取消勾选保存），再将 `rc.39` 解压到新目录并视需要拷贝 `data/`。
- **SSH 凭证管理与 SSH Tunnel 端口转发（保留原 Xray 端口转发）**：
  - **SSH 凭证管理（账号与密码 / 私钥）**：在「配置 → 端口转发 → SSH 凭证」集中管理账号、密码或私钥文件（可选口令）；Windows 下采用当前用户 DPAPI（`CryptProtectData`）加密落盘，IPC、界面与日志永不回显明文密码，删除前校验引用关系。
  - **SSH 跳板机与 Host Key 核验**：在「SSH 跳板机」关联凭证并支持一键握手探测与固定服务器 `SHA256` Host Key 指纹（握手指纹不匹配直接拦截拒绝）。
  - **端口转发统一管理 + 总览按需启停**：在「添加/编辑端口转发」选择 Xray 出站时继续走原 `dokodemo-door`（支持 TCP/UDP）；选择 SSH 跳板机时强制 TCP、不修改 Xray `config.json`、统一校验端口冲突，并由 `proxy-supervisor` 内置纯 Rust `russh` 引擎直接提供 `direct-tcpip` 本地端口转发。在 **「总览 → 运行中端口转发清单」** 可随时对每条 SSH 转发独立 **启动 / 停止**，不依赖 Core 是否启动。
- **修复重启 Core / 切换代理模式误报 `ASSET_REVISION_CONFLICT`**：
  - 明确区分 `ApplyProfile`（需校验配置版本并提升正式配置）与 `RestartCore` / `SetProxyMode`（仅作用于已提交的冻结 `Candidate`），修复草稿自动保存（`UpdateProfile`）后点击「重启当前运行版本」或切换代理模式时失败报错并覆盖磁盘草稿的问题。

## 验证

在提交与构建打包前执行 `cargo fmt --all -- --check`、`git diff --check`、Linux 与 `x86_64-pc-windows-gnu` 双目标严格 Clippy（`-D warnings`）、全工作区 `--locked` 回归测试（含新增 SSH 存储脱敏测试、Mock SSH Server 端到端 TCP 转发与指纹篡改拦截测试、总览按需启停 UI 测试及重启不触发 `ASSET_REVISION_CONFLICT` 集成测试），以及 Windows x64 release 交叉编译与 `scripts/package-windows.py --validation` CRC / 指纹校验。
