# Proxy Pilot v0.1.1-rc.52

Windows x64 本地验证版，在 `v0.1.1-rc.51` 的基础上新增 **通用节点分享链接与离线二维码**（场景 1）以及 **支持口令加密与无凭证 SSH 拓扑的完整配置包导出/导入**（场景 2），并将「配置」页顶栏「导出 JSON」升级为跨平台的 **「分享 / 导出」**。**本版尚未发布到 GitHub Release**。

## 本次变化

- **通用节点分享链接编码与离线二维码（[share_link.rs](../../crates/proxy-config/src/share_link.rs)、[share.rs](../../crates/proxy-manager-app/src/ui/share.rs)、[guided_config/ui.rs](../../crates/proxy-manager-app/src/guided_config/ui.rs)）**：
  - 在 `proxy-config::share_link` 补齐对称反向编码器（`encode_share_link` / `encode_share_links` / `format_share_links_text`），支持 `vless://`、`trojan://`、`ss://`（SIP002）、`vmess://`、`socks://`、`http://` / `https://`，自动跳过内置系统出站（`freedom` / `blackhole` / `dns`），并对 `mux`、`sockopt`、多服务器/多用户、自定义请求头等标准 URI 无法表达的字段输出有损提示。
  - 引入纯 Rust 离线二维码生成（`qrcodegen`），在浅色/深色主题下统一以高对比度白底黑码 + 标准留白绘制，超长链接自动降级提示。
  - 在 **配置 → 节点** 各可分享节点卡片新增 **「分享」** 快捷按钮，支持单节点链接/二维码复制，以及多节点明文或 Base64 批量复制。
- **完整配置包、口令加密与无凭证 SSH 拓扑（[bundle.rs](../../crates/proxy-config/src/bundle.rs)、[resources.rs](../../crates/proxy-config/src/resources.rs)、[proxy-model/src/lib.rs](../../crates/proxy-model/src/lib.rs)）**：
  - 定义版本化 `proxy-pilot-bundle`（`schema_version = 1`），支持 `.ppbundle.json` 文件与紧凑压缩文本分享码（`ppbundle1:` + gzip + Base64URL），携带 Xray 原生配置、节点/转发显示名称与停用暂存（`PausedPortForward`）、记忆的代理模式与 PAC 策略、以及可选 SSH 跳板机与隧道拓扑。
  - 支持可选 **Argon2id + AES-256-GCM** 口令加密与 AAD 完整性校验；导出时自动检测跨平台绝对资源路径（`absolute_resource_paths`）给出迁移提示，并**严格排除 SSH 密码、口令与私钥路径**。
- **统一「分享 / 导出」与「配置包导入预览」（[profiles.rs](../../crates/proxy-manager-app/src/ui/profiles.rs)、[dialogs.rs](../../crates/proxy-manager-app/src/ui/dialogs.rs)、[app.rs](../../crates/proxy-manager-app/src/app.rs)、[ui.rs](../../crates/proxy-manager-app/src/ui.rs)）**：
  - 「配置」页编辑卡片顶栏将仅限 Windows 的「导出 JSON」升级为跨平台的 **「分享 / 导出」**，弹窗内分「节点链接 / 二维码」「完整配置包」「原生 JSON」三选项卡，关闭后自动清理内存中的口令与生成分享码。
  - 在 **添加 / 导入配置** 支持自动识别 `.ppbundle.json` 与 `ppbundle1:` 分享码、本地口令解密、内容摘要预览及 SSH 跳板机逐台处理（复用已有跳板机 / 绑定已有凭证 / 内联新建凭证 / 跳过），并通过 `App::enqueue_write` 顺序安全落地配置与 SSH 拓扑（失败时中止后续依赖写入，且不自动重启 Core）。
- **回归测试与文档（[tests.rs](../../crates/proxy-manager-app/src/ui/tests.rs)、[README.md](../../README.md)、[validation-guide.md](../validation-guide.md)）**：
  - 在 `proxy-config` 新增 6 项协议编解码与加密配置包/防篡改/防膨胀/SSH 脱敏单测；在 `proxy-manager-app` 更新顶栏对齐断言并新增 `share_dialog_renders_qr_links_bundle_and_raw_json_without_overlap` 与 `bundle_import_roundtrip_encrypted_with_pac_and_ssh_topology` 回归测试。
