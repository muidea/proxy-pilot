# Proxy Pilot v0.1.1-rc.44

Windows x64 本地验证版，在 `v0.1.1-rc.43` 的基础上，全面核对并统一总览页（「管理端口转发」「打开路由诊断」「前往管理」「启动/停止」「查看日志/隐藏」）与各子页面/弹窗中按钮的显示风格与高度。**本版尚未发布到 GitHub Release**。

## 本次变化

- **统一全界面按钮风格与 `36 px` 控件高度**：
  - 移除总览页（[layout.rs](../../crates/proxy-manager-app/src/ui/layout.rs)）中「管理端口转发」「打开路由诊断」「前往管理」「启动/停止」「查看日志/隐藏」原 `small_button`/`.small()` 调用（`egui` 的 `.small()` 会覆盖垂直内边距为 `0` 并绕过 `CONTROL_HEIGHT = 36.0`，导致「打开路由诊断」与同行 `[直连] [PAC] [全局]` 分段按钮及卡片内其他按钮高度/内边距明显不一致），统一采用标准 `36 px` 按钮风格（`12×8` 内边距、`1.0 px` `border_strong` 边框、`8 px` 圆角）。
  - 同步全面核对并收口其余页面中同类的偏差按钮：包括配置页入站/转发/SSH 卡片按钮与「前往端口转发」「前往新建凭证」（[profiles.rs](../../crates/proxy-manager-app/src/ui/profiles.rs)）、引导配置节点/规则操作与预设按钮（[guided_config/ui.rs](../../crates/proxy-manager-app/src/guided_config/ui.rs)）、弹窗「+ 新建 SSH 跳板机」「+ 新建凭证」（[dialogs.rs](../../crates/proxy-manager-app/src/ui/dialogs.rs)）、PAC「清除」「复制 URL」（[pac.rs](../../crates/proxy-manager-app/src/ui/pac.rs)）、诊断快捷入站按钮（[diagnostics.rs](../../crates/proxy-manager-app/src/ui/diagnostics.rs)）及原生字段删除按钮（[native_editor.rs](../../crates/proxy-manager-app/src/native_editor.rs)）。
  - 在 [widgets.rs](../../crates/proxy-manager-app/src/widgets.rs) 新增带 `1.0 px` `border_strong` 边框、圆角 `6 px`、`24 px` 高度与合理内边距的 `compact_button`，仅用于 PAC 虚拟滚动域名列表行「移除」与日志逐行「复制」等高密度行内操作，避免撑高列表行或产生文字裁剪。
  - 新增 `ui::tests::overview_action_buttons_match_standard_control_height` 回归测试，校验总览页按钮高度与同行基线对齐且无文字重叠。

## 验证

在提交与构建打包前执行 `cargo fmt --all -- --check`、`git diff --check`、Linux 与 `x86_64-pc-windows-gnu` 双目标严格 Clippy（`-D warnings`）、全工作区 `--locked` 回归测试（**290 项通过**，含 `proxy-manager-app` **131 项**、`proxy-supervisor` 库 **51 项**、`windows-integration` **11 项**、集成回归 **31 项**，7 项需 `XRAY_TEST_CORE` 的环境专项按预期忽略），以及 Windows x64 release 交叉编译与 `scripts/package-windows.py --validation` CRC / 指纹校验。
