# Proxy Pilot v0.1.1-rc.40

Windows x64 本地验证版，在 `v0.1.1-rc.39` 的基础上，优化 **全部弹出框边框质感、留白与分级宽度及标题字号层级**，并同步 **对齐 `windows-smoke.ps1 -Gui` 托盘退出流程与全部设计/验证/遗留项文档**。**本版尚未发布到 GitHub Release**。

## 本次变化

- **弹出框视觉与层级协调优化**：
  - 为常规工作区弹窗（`workspace-dialog`）与发布前预览弹窗（`candidate-preview`）统一配置 `dialog_frame`（`1.0 px` `border_strong` 边框、`12 px` 圆角、`20×16` 内边距与 `popup_shadow`）及 `alpha=115` 遮罩，替代原本偏窄的默认 `Frame::popup` 边距。
  - 按内容复杂度分级设置弹窗最大宽度：紧凑确认与退出选择（`Confirm` / `ExitChoice`）收敛至 `500 px`；表单与未保存退出（`PortForward` / `SshCredential` / `SshHost` / `UnsavedExit`）为 `580 px`；历史差异对比为 `700 px`；新建/导入、PAC 批量编辑与应用预览为 `780 px`，在 `1100×760` 默认窗口下留白更均匀，在 `760×500` 最小窗口下继续完整防裁剪。
  - 弹窗标题字号由 `22.0` 调整为与页面分节卡片一致的 **`18.0`**（加粗），副标题调整为 `12.5` 并增加与操作分隔区的对称留白。
- **验证脚本与文档核对对齐**：
  - 更新 `scripts/windows-smoke.ps1 -Gui`，使其按当前托盘单项 `退出…` 验证关闭隐藏、托盘唤醒确认窗、`--background` 保持隐藏及停机清理流程。
  - 核对并同步 `README.md`、`docs/validation-guide.md`、`docs/development.md`、`docs/handoff.md`、`docs/phase0-2-backlog.md`、`docs/phase0-2-design-crosscheck.md`、`docs/implementation-status.md`、`docs/configuration-interaction.md` 与架构设计文档。

在提交与构建打包前执行 `cargo fmt --all -- --check`、`git diff --check`、Linux 与 `x86_64-pc-windows-gnu` 双目标严格 Clippy（`-D warnings`）、全工作区 `--locked` 回归测试（**283 项通过**，含新增双主题/双尺寸弹窗框度与标题布局回归 `modal_dialogs_use_balanced_widths_padding_and_harmonized_title_size`，7 项需 `XRAY_TEST_CORE` 的环境专项按预期忽略），以及 Windows x64 release 交叉编译与 `scripts/package-windows.py --validation` CRC / 指纹校验。
