# Xray Pilot v0.1.1-rc.35

Windows x64 本地验证版，在 `v0.1.1-rc.34` 实测反馈的基础上，按新版交互原型完成 `xray-manager-app` 桌面端整体布局、视觉层次与交互对齐重构。**本版尚未发布到 GitHub Release**。

## 本次变化

- **统一顶部窗口栏（移除左侧竖栏）**：将旧版左侧 190px 导航栏与面包屑顶栏合并为统一顶部栏，包含实时运行状态胶囊（`Core 运行中 · <模式> · <N> 条转发` / `Core 已停止` / `后台未连接`）、水平页面标签（`总览 / 配置 / PAC / 诊断 / 日志 / 设置`）与右侧版本号，释放主操作区宽度。
- **总览页两栏重构**：
  - 左侧 **连接与系统代理状态** 卡片移除「网络连通性：未检测」「实际出口：未验证」等占位文本，保留核心代理状态、`生效 PAC 策略`、`端口转发` 统计、快捷模式切换及跳转操作。
  - 右侧 **运行中端口转发清单** 卡片常驻展示（即使 Core 已停止或暂无条目也有清晰状态说明），突出转发链路与与系统代理直连模式相互独立的提示条。
- **配置页（`Profiles`）组件全面卡片化与胶囊化**：
  - 顶部 **代理方式** 改为 `[直连] [PAC] [全局]` 分段按钮，旁侧直接以胶囊显示 `HTTP: <endpoint>` / `无 HTTP 入口`。
  - **节点（`Outbounds`）**：由折叠行改为默认可见节点卡片，直接显示节点名、`tag`、`protocol`、`默认访问` 绿标、`被 N 条端口转发引用` 告警标与卡内快捷按钮（`设为默认`、`编辑参数`/`收起参数`、`删除节点`）。
  - **分流规则（`Routing`）**：端口转发置顶联动卡片升级为圆角徽章与流向条样式。
  - **端口转发**：卡片采用协议/Tag/生效状态/局域网暴露徽章、`flow_strip` 流向条（`监听 -> 经由 -> 目标`）及分级告警 `banner_box`。
  - **更多与源码 → 本地入口**：新增 `常用卡片 | 高级：原生字段编辑` 切换；默认展示可一键添加 HTTP/SOCKS 入站、行内编辑监听与端口冲突提示的入站卡片，并汇总 `dokodemo-door` 转发映射及快捷跳转按钮。
- **诊断页（`Diagnostics`）常驻探针卡片与快捷填入**：
  - 新增常驻 **本地入口与端口转发就绪状态** 卡片，以 `协议握手就绪` / `TCP 监听就绪` / `UDP 转发已校验（不做 TCP 探针）` / `Core 未运行` 等彩色胶囊展示各入站状态。
  - 点击入站 `tag` 胶囊或下方 **快捷入站** 按钮可直接将对应入站及转发目标回填至 **路由静态预测** 表单，预测出站与命中规则同步以徽章高亮显示。

## 验证

在构建打包前执行 `cargo fmt --all -- --check`、Linux 与 `x86_64-pc-windows-gnu` 双目标严格 Clippy（`-D warnings`）、全工作区回归测试（所有单元测试与集成测试 0 失败；仅 6 个依赖外部 `XRAY_TEST_CORE` 用例按预期忽略），以及 Windows x64 release 交叉编译与 `scripts/package-windows.py --validation` CRC / 指纹校验。
