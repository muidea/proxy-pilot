# Xray Pilot v0.1.1-rc.37

Windows x64 本地验证版，在 `v0.1.1-rc.36` 的基础上，优化顶部导航优先级排序与方向布局，并按「方案 A」实现配置切换时代理方式与 PAC 策略的按配置独立记忆。**本版尚未发布到 GitHub Release**。

## 本次变化

- **顶部导航菜单按使用优先级重排与方向修复**：
  - 调整顶部导航顺序为 **`总览 → 配置 → PAC → 日志 → 诊断 → 设置`**（将高频观测与级别切换的「日志」前置，专项排障「诊断」与低频系统「设置」后置）。
  - 修复 `egui::Sides` 右侧闭包继承 `right_to_left` 导致的菜单及「代理方式：`[直连] [PAC] [全局]`」分段按钮反序渲染问题，现已严格从左到右排列。
- **方案 A：切换配置时各自保留代理方式与 PAC 策略**：
  - `Workspace`（`config/gui.json`）新增 `proxy_modes`（按 `profile_id` 存储各配置的 `Direct` / `Pac` / `Global`；未设置或新建配置默认 `Direct`），与 `pac`（`PacDraft`）一起实现完全按配置隔离。
  - 切换配置自动恢复该配置记住的 `ProxyMode` 与 `PacDraft`；配置页切换模式、PAC 页应用、总览页快捷切换及删除配置清理均保持双向同步；左侧「我的配置」卡片同步标出各配置当前记住的代理方式。

## 验证

在构建打包前执行 `cargo fmt --all -- --check`、Linux 与 `x86_64-pc-windows-gnu` 双目标严格 Clippy（`-D warnings`）、全工作区锁定回归测试（含新增导航从左到右顺序断言与方案 A 跨配置隔离回归），以及 Windows x64 release 交叉编译与 `scripts/package-windows.py --validation` CRC / 指纹校验。
