# Xray Pilot v0.1.1-rc.31

Windows x64 本地验证版，在 `v0.1.1-rc.30` 的基础上，围绕配置管理进一步简化步骤与心智负担：落地 `UpdateProfile` 自动保存与异常兜底状态模型（3A）、「检查并应用」一键化串联、纯本地离线分享链接解析与批量导入，以及配置标签页与首次引导流程收敛。**本版尚未发布到 GitHub Release**。

## 本次变化

- **3A 自动保存与运行快照分离（`crates/xray-model`、`crates/xray-supervisor`、`crates/xray-manager-app`）**：
  - 新增 `Command::UpdateProfile`，经 `EffectJournal` 原子写回 `config/profiles/<id>/config.json` 并核对 `expected_revision`，不重启 Core 且不改变运行中 `Generation`。
  - GUI 在编辑防抖后对合法 JSON 自动落盘，仅在存在未完成数值输入或暂不可解析 JSON 时退回 `config/editor-drafts/` 兜底缓冲；提供「还原运行版」一键恢复当前运行配置内容，日常切换配置无多余确认弹窗。
- **纯本地离线分享链接解析（`crates/xray-config/src/share_link.rs`、`crates/xray-manager-app`）**：
  - 新增离线 URI 解析器（无任何网络请求），支持 `vless://`（Reality/TLS 与 tcp/ws/grpc/httpupgrade/xhttp/splithttp/kcp/quic）、`trojan://`、`ss://`（SIP002 & Legacy）、`vmess://`（v2rayN Base64 JSON）、`socks://`、`http://` 以及多行 / Base64 离线清单批量导入；遇到 `allowInsecure=1` 时显式提示风险。
  - 在新建配置弹窗与「配置 → 节点」页均提供从分享链接快速填入 / 批量导入入口。
- **「检查并应用」一键化与界面流程收敛（`crates/xray-manager-app`）**：
  - 底栏主按钮升级为「检查并应用」（保留「预览变更」）：校验通过且无资源覆盖警告、`allowInsecure` 提示或从直连首次切换系统代理接管时自动串联 `ApplyProfile`，存在警告或首次代理接管时弹出预览确认窗。
  - 配置页由 6 个标签收敛为 **「节点」「分流规则」「更多与源码（本地入口 / 原始 JSON / 历史版本）」**；新建弹窗移除「开始填写」中间步骤，「按网站分流」默认勾选国内外 GeoSite/GeoIP 预设与本地入口 Sniffing；支持标题行内改名与节点卡片一键「设为默认」；代理方式上提至标签行并自动绑定单个兼容 HTTP/Mixed 入站；首次设置合并为 2 步直达。

## 验证

在构建打包前执行 `cargo update --workspace --offline`、`cargo fmt --all -- --check`、Linux 与 `x86_64-pc-windows-gnu` 双目标严格 Clippy（`-D warnings`）、全工作区回归测试，以及 Windows x64 交叉编译与包校验（`--validation` 本地验证包）。
