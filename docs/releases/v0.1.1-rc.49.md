# Proxy Pilot v0.1.1-rc.49

Windows x64 本地验证版，在 `v0.1.1-rc.48` 的基础上修复 **「配置 → 端口转发 → 转发规则」跨字体/中等窗口下的首屏可视高度布局**，并保留 `rc.48` 完整 Xray 代理可用性自动探测与五步诊断报告能力。**本版尚未发布到 GitHub Release**。

## 本次变化

- **「转发规则」头部精简与断草稿告警置顶（[profiles.rs](../../crates/proxy-manager-app/src/ui/profiles.rs)）**：
  - 将 `转发规则 / SSH 跳板机 / SSH 凭证` 子标签栏与 `+ SSH 隧道` / `+ Xray 转发` 按钮合并进同一 `responsive_header` 行，下方仅保留紧凑汇总徽章与单行说明，释放约 `140 px` 首屏纵向空间，同时保持 `profiles_page` `840 px` 双栏断点。
  - 当 Xray 草稿存在 JSON 语法错误（`parsed_value.is_none()`）时，将警告条直接置于汇总行正下方、SSH 隧道列表之前，避免无系统中文字体（如 Linux CI 默认回退字体）或不同字形度量下将新增转发卡片或告警条挤出 `ScrollArea("profile-body")` 可视区域。
- **跨字体与中等尺寸自动化回归测试（[ui.rs](../../crates/proxy-manager-app/src/ui.rs)、[tests.rs](../../crates/proxy-manager-app/src/ui/tests.rs)）**：
  - 提取 `apply_base_style` 与测试辅助 `configure_without_system_cjk`，新增 `port_forward_tab_and_broken_json_remain_visible_without_system_cjk_font` 模拟无系统中文字体环境下的端口转发创建与断草稿展示。
  - 在 `profiles_page_adapts_across_window_sizes_without_clipping_headers_or_controls` 纳入 `(880.0, 860.0)` 检查，并在宽度切换时等待布局收敛帧。
