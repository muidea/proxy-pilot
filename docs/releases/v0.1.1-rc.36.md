# Xray Pilot v0.1.1-rc.36

Windows x64 本地验证版，在 `v0.1.1-rc.35` 实测对照原型的基础上，完成全局视觉系统与 6 大页面排版/交互的深度对齐。**本版尚未发布到 GitHub Release**。

## 本次变化

- **全局原型色板与控件对齐**：将旧版蓝绿主题替换为原型冷灰底色与 `#1d6fe8` / `#4d97ff` 主题蓝系统（卡片、次级面板、边框、实心蓝主按钮、高亮选中项、分级告警条与状态胶囊全部统一）。
- **顶部窗口栏**：新增状态指示圆点（运行绿点带柔光圈 / 停止灰点）、包含运行配置名与转发监听数的实时状态胶囊、右侧对齐的无边框圆角页面导航胶囊。
- **总览页（`Overview`）去旧迎新**：移除旧版大字体 `XRAY CORE` Hero 区块，改为页面标题右侧直接呈现生命周期控制按钮（`停止 Core` / `重启当前运行版本` / `启动上次应用版本` / `管理配置`），首屏直接进入原型两栏仪表盘（左侧 **连接与系统代理状态** + 快捷模式切换，右侧常驻 **运行中端口转发清单**）。
- **配置页（`Profiles`）与表单彻底对齐**：
  - 左侧配置栏采用左对齐两行卡片条目，选中态带蓝色边框与浅蓝高亮底色；
  - 页签栏改为实心蓝色激活态胶囊，右侧并排 `[直连] [PAC] [全局]` 分段按钮与 `HTTP` 入口状态胶囊；
  - 端口转发卡片采用标准 `.card-top` 排版（`复制监听地址 / 编辑 / 删除` 右上角与标题同行），停用卡片呈现淡色底框，异常/缺出站卡片显示红色告警边框；
  - 出站节点卡片、分流规则卡片、本地入口卡片与「端口转发」新增/编辑弹窗中的分段选择、分级 `banner_box` 均按原型统一。

## 验证

在构建打包前通过 `cargo fmt --all -- --check`、Linux 与 `x86_64-pc-windows-gnu` 双目标严格 Clippy（`-D warnings`）、全工作区锁定回归测试，以及 Windows x64 release 交叉编译与 `scripts/package-windows.py --validation` CRC / 指纹校验。
