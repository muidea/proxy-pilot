# Proxy Pilot v0.1.1-rc.45

Windows x64 本地验证版，在 `v0.1.1-rc.44` 的基础上，完成 **总览页核心控制按钮向「连接与系统代理状态」卡片归拢及简短等长文案统一**，并包含 `proxy-model` Windows 无盘符根路径便携判定修复。**本版尚未发布到 GitHub Release**。

## 本次变化

- **总览页布局归拢与按钮文案统一（[layout.rs](../../crates/proxy-manager-app/src/ui/layout.rs)）**：
  - 精简总览页首为纯粹的「总览」标题与定位副标题，将原本位于页首的 Core 与配置控制按钮归拢到左侧「连接与系统代理状态」卡片底部的统一操作栏。
  - 状态行对齐优化：`当前配置`（运行中显示配置名，有历史已停止显示 `{name}（已停止）`，无历史显示 `尚未应用配置`）与 `Xray 端口转发` 均采用统一 `kv_row` 排版，不再在状态行中插放按钮。
  - 统一简短 4 字动宾按钮文案与状态分支去重：
    - 运行中：`停止 Core` · `重启 Core` · `管理配置` · `路由诊断`
    - 有历史已停止：`启动 Core`（主色） · `管理配置` · `路由诊断`
    - 无历史已停止：`选择配置`（主色） · `路由诊断`
  - 快捷代理切换区标签精简为 `代理模式` + `[直连]` `[PAC]` `[全局]`；右侧卡片统一为「端口转发与隧道」及「管理转发」（合并原左右两处重复跳转入口），未运行引导文案与左侧「启动 Core」/「选择配置」保持一致。
  - 更新 `ui::tests::overview_action_buttons_match_standard_control_height` 等回归，覆盖运行中、有历史已停止、无历史已停止三种状态下的按钮高度与排版无重叠。
- **Windows 便携路径根判定修复（[crates/proxy-model/src/lib.rs](../../crates/proxy-model/src/lib.rs)）**：
  - 修复 `to_portable_path` 与 `resolve_path` 在 Windows 下将无盘符根路径（`has_root() == true` 但 `is_absolute() == false`）误判为相对路径的问题，保护驱动器相对路径并补充 Windows 盘符/`\\?\` 回归测试。

## 验证
