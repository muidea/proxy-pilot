# Xray Pilot v0.1.1-rc.29

Windows x64 本地验证版，在 `v0.1.1-rc.28`（退出前代理连接方式自动恢复）的基础上，对照 [Xray 加载与使用 Geo 规则文件完整指南](../Xray%20加载与使用%20Geo%20规则文件完整指南.md) 完成 Geo 规则加载、分流前置开关向导、静态预测与 PAC Geo 缓存的收口。**本版尚未发布到 GitHub Release**。

## 本次变化

- **分流前置开关向导与校验提示（`crates/xray-manager-app`、`crates/xray-config`）**：
  - 路由表单新增紧凑横向 `域名解析策略 (domainStrategy)` 选择器（`AsIs` / `IPIfNonMatch` / `IPOnDemand`），点击 **国内外分流预设 (GeoSite)** 时自动将未设置或 `AsIs` 的 `domainStrategy` 设为 `IPIfNonMatch`；
  - 路由工具栏新增 **开启 Sniffing** 一键按钮，为全部入站启用 `sniffing`（保留已有 `domainsExcluded` 等字段，补全 `enabled: true`、`destOverride: ["http", "tls", "quic"]` 与 `routeOnly: true`）；
  - `inspect_config` 新增非阻塞配置核对提示：在存在 `ip` 规则却为 `AsIs`、存在 `geosite:`/`ext:` 规则但入站未启用 `sniffing`，或启用 `sniffing` 但未设置 `routeOnly: true` 时提示用户核对。
- **`ext:` / `ext-ip:` / `domainsExcluded` 与 0 字节 `.dat` 校验收口（`crates/xray-config`、`crates/xray-supervisor`）**：
  - 修复 `routing::simulate_with_geo` 预小写化导致含大写字母的 `ext:Custom.dat:tag` 查表失败的问题，并为 `geodata::matches_ip_spec` 与 `routing::ip_match` 补充 `ext-ip:` 前缀支持；
  - `resources::collect_referenced_geo_files` 补充扫描 `/inbounds[*]/sniffing/domainsExcluded` 并统一大小写不敏感前缀匹配；`freeze_with` 与 `GeoSiteIndex::parse`/`GeoIpIndex::parse` 显式拒绝 0 字节 `.dat` 空文件（返回 `INVALID_GEODATA`）；
  - 新增 `GeoData::load_from_asset_root_best_effort` 供 `load_candidate_geodata` 与 PAC 缓存使用，避免单个 `.dat` 损坏导致另一个索引与 `asset_root` 丢失。
- **PAC Geo 缓存与引导文案完善（`crates/xray-manager-app`）**：
  - `refresh_geodata_cache` 支持在无 `geosite.dat` 时仅加载配置引用的 `ext:*.dat`，并将配置 `ext:` 引用变化与文件元数据纳入缓存指纹；当 `geosite.dat` 为空或解析失败时展示明确的 `geosite_error` 提示；
  - 完善 `CORE_VALIDATION_FAILED` 提示与设置页资源目录 `.dat` 格式说明（官方版 / `Loyalsoldier/v2ray-rules-dat`，勿将 `.db`/`.srs` 改名）。

## 验证

在构建打包前执行 `cargo update --workspace --offline`、`cargo fmt --all -- --check`、Linux 与 `x86_64-pc-windows-gnu` 双目标严格 Clippy（`-D warnings`）、全工作区回归测试、`git diff --check` 以及 Windows x64 交叉编译与包校验。
