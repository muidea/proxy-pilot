# Proxy Pilot v0.1.1-rc.51

Windows x64 本地验证版，在 `v0.1.1-rc.50`（含基于 `rc.49` 未提交的总览双卡样式统一与三层按钮对称排布、`ETXTBSY` 启动重试加固）的基础上，进一步重构 **「配置」页编辑卡片顶栏布局**，解决配置状态徽章夹在操作按钮之间的问题。**本版尚未发布到 GitHub Release**。

## 本次变化

- **「配置」页编辑卡片顶栏结构重构（[profiles.rs](../../crates/proxy-manager-app/src/ui/profiles.rs)）**：
  - 使用 `responsive_header(ui, 560.0, ...)` 将编辑卡片顶栏拆为清晰的左右两组：
    - **左侧（标题与状态归组）**：配置名称（超长时为右侧状态徽章预留 `128 px` 并单行 `.truncate()` + 悬停完整名）或内联改名输入框紧接状态徽章（`运行中` / `已保存` / `未落盘修改` / `已保存 · 待应用`），状态标签紧贴标题展示，不再被拆到按钮中间。
    - **右侧（操作按钮归组）**：常规态统一靠右排布为 `[改名] [复制] [删除] [导出 JSON]`（`导出 JSON` 仅 Windows），内联改名态靠右排布为 `[确定] [取消]`；按 `rtl` 正确保序并在窄于 `560 px` 时自动两行叠放；对不可复制/删除/导出的禁用按钮改为 `on_disabled_hover_text`，仅在禁用时提示原因。
- **「配置」页顶栏回归测试（[tests.rs](../../crates/proxy-manager-app/src/ui/tests.rs)）**：
  - 新增 `profile_editor_header_keeps_status_beside_title_and_groups_actions`，覆盖 `[760, 880, 980, 1100, 1440]` 宽度下的正常态排序、60+ 字符超长名称 + 最长徽章 `已保存 · 待应用` 单行截断不挤压，以及内联改名态按钮对齐校验。
- **同期包含（基于 `rc.49` 未提交修改，`rc.50` 验证内容）**：
  - **「总览」双卡样式统一、三层功能按钮对称排布与单行防折行优化**（[widgets.rs](../../crates/proxy-manager-app/src/widgets.rs)、[layout.rs](../../crates/proxy-manager-app/src/ui/layout.rs)、[tests.rs](../../crates/proxy-manager-app/src/ui/tests.rs)）。
  - **Linux/Unix 子进程启动瞬态 `ExecutableFileBusy` (`ETXTBSY`) 退避重试加固**（[lib.rs](../../crates/proxy-runtime/src/lib.rs)、[process.rs](../../crates/proxy-runtime/src/process.rs)）。

## 验证

在构建打包前执行 `cargo update --workspace --offline`、`cargo fmt --all -- --check`、`git diff --check`、Linux 与 `x86_64-pc-windows-gnu` 双目标严格 Clippy（`-D warnings`）、全工作区 `--locked` 回归测试（**311 项通过**：含 `proxy-manager-app` **142 项**、`proxy-supervisor` 库 **60 项**、`proxy-config` **33 项**、`proxy-pac` **20 项**、`proxy-runtime` **13 项**、`proxy-model` **1 项**、`windows-integration` **11 项**、集成回归 **31 项**，7 项需 `XRAY_TEST_CORE` 的环境专项按预期忽略），以及 Windows x64 release 交叉编译与 `scripts/package-windows.py --validation` CRC / 指纹校验。
